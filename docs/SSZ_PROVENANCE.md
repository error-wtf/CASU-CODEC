# Provenance

Every important result should follow:

`claim → formula and scope → implementation → input data → test → result artefact → commit/release`

Five central chains are encoded in `data/provenance.json`: finite horizon dilation, far-field asymptotics, C² blending, central non-regularity and PPN compatibility.

Missing links reduce epistemic status. A plot without a derivation, a PASS without a command, or a fit without data provenance is not promoted.
